# 🏡 Домклик Парсер — Telegram Бот

Бот ищет дома с участком на Домклик и присылает уведомления о новых объявлениях.

## Быстрый старт

### Шаг 1 — Создать бота в Telegram
1. Открой Telegram, найди `@BotFather`
2. Отправь `/newbot`
3. Придумай имя (например: `Мой поиск домов`)
4. Придумай username (например: `my_domclick_bot`)
5. Скопируй **токен** — строка вида `7123456789:AAHxxx...`

### Шаг 2 — Узнать свой Telegram ID
1. Напиши боту `@userinfobot` в Telegram
2. Он пришлёт твой числовой ID (например: `123456789`)

### Шаг 3 — Загрузить на GitHub
1. Зарегистрируйся на [github.com](https://github.com)
2. Нажми `+` → `New repository`
3. Назови `domclick-bot`, сделай `Private`, нажми `Create`
4. Загрузи все 5 файлов проекта (`bot.py`, `parser.py`, `config.py`, `requirements.txt`, `Procfile`)

### Шаг 4 — Запустить на Railway
1. Открой [railway.app](https://railway.app) → войди через GitHub
2. `New Project` → `Deploy from GitHub repo` → выбери `domclick-bot`
3. Перейди в `Variables` и добавь:
   - `BOT_TOKEN` = твой токен от BotFather
4. Railway автоматически установит зависимости и запустит бота

### Шаг 5 — Использование
Открой своего бота в Telegram и нажми `/start`

## Команды бота
- `🔍 Искать сейчас` — немедленный поиск по фильтрам
- `⚙️ Фильтры` — настроить регион, цену, площадь
- `🔔 Автопоиск` — включить уведомления каждые 30 минут
- `📋 Мои настройки` — посмотреть текущие фильтры

## Переменные окружения
| Переменная | Описание |
|-----------|----------|
| `BOT_TOKEN` | Токен бота от @BotFather |
